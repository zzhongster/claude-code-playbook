# OSMD 手机排版：隐藏钢琴声部 + 两遍排版限制每行最多 N 小节

## 一句话结论

375px 宽的手机上，人声 + 钢琴大谱表三行一叠再加两段歌词，OpenSheetMusicDisplay 每行只排得下 1 小节，一屏 2 小节，唱的人看不到前后乐句。隐藏非主声部（`Instrument.Visible = false`）是主要收益，缩放是次要收益；OSMD 1.8.4 没有"每行固定 N 小节"规则，等宽小节会让密集小节的歌词互相叠上，注入换行强制每行 3 会出现被拉满整行的孤单小节。稳的做法是**两遍排版**：第一遍自动分行，把超过 N 的行均匀拆开，在 MusicXML 里注入 `<print new-system="yes"/>` 并打开 `NewSystemAtXMLNewSystemAttribute` 再排一遍——永远 ≤N、不孤行、不重叠。

## 场景

- 用 OSMD 在手机上渲染带钢琴伴奏的声乐谱 / 器乐谱，用户主要看主声部
- 原版 PDF 是 A4 每行 5 小节的整齐排版，用户希望手机上也"一行几小节、整整齐齐"

## 详细说明

### 先量化，别凭感觉

用 Playwright 起一个 375×812 的页面加载 OSMD，对每种配置输出：每行小节数（`MusicSystem.GraphicalMeasures.length`）、一屏小节数、横向溢出（所有 svg 元素的 `getBoundingClientRect().right` 与容器右缘比）、歌词重叠（同基线相邻中文 `<text>` 的 x 区间相交计数）。三首不同密度的曲子一起跑，避免调参调到一首曲子上。

### 各条路的结果

| 配置 | 每行小节 | 一屏小节 | 问题 |
|------|---------|---------|------|
| 现状（三行谱表，缩放 1.0） | 1.0 | 2.3 | |
| 保留钢琴，缩到 0.6 | 2.2 | 8 | 五线谱只有 24px 高 |
| 只隐藏钢琴，缩放 1.0 | 1.3 | 7 | 歌词仍把小节撑宽 |
| 隐藏钢琴 + 0.7 + 紧凑间距 | 3.1 | 22 | 行与行差别大，有的行 6–7 小节 |
| 等宽小节（`FixedMeasureWidth`）0.6 | 2.9 | 25 | 密集曲目 12 处歌词重叠 |
| 强制每行 3（每 3 小节注入换行）0.6 | 2.8 | 24 | 3 小节塞不下时 OSMD 自行拆行，落单小节被拉满整行 |
| **每行最多 3（两遍排版）0.7** | 2.4 | 18 | 无 |

紧凑间距的规则值：`VoiceSpacingMultiplierVexflow = 0.65`、`VoiceSpacingAddendVexflow = 2.0`、`LyricsHeight = 1.6`。

### 两遍排版的实现要点

1. `osmd.load(xml)` → 设可见性 / 缩放 / 间距规则 → `render()`
2. 遍历 `GraphicSheet.MusicPages[].MusicSystems`，每行 n 小节，`k = ceil(n / cap)`，均匀拆成 k 段（7 → 3+2+2，不是 3+3+1），记下每段首小节在第一声部里的序号
3. 用 DOMParser 去掉原谱所有 `print` 的 `new-system` / `new-page`（原版 PDF 的换行是按 A4 排的，不能留），在记下的小节里插入 `<print new-system="yes"/>`，序列化
4. 再次 `load` → 再设一遍可见性（`Sheet` 是新的）→ `EngravingRules.NewSystemAtXMLNewSystemAttribute = true` → `render()`
5. 拆出来的段都是第一遍里排得下的子集，所以不会溢出；OSMD 若仍嫌某段太挤会自己再拆，只会更少不会更多

### 光标与时间线

- 隐藏声部后 `cursor` 迭代步数从 444 降到 231（只剩人声的音符与休止），68 个小节全部到达；按"小节 + 拍位"映射 MIDI 时间线的引擎不受影响，直接以最终排版重新走一遍光标即可
- 排版变更（开关钢琴谱、缩放）后要整体重载：记下 `currentTime`，重载完 `seekTo` 回去

### 截图会骗人

探针截图里整屏都是谱面，一屏 18 小节；用户手机上 Safari 上下两条栏占 179px、页面自己的标题栏和控制条占 156px，谱面只剩六成屏幕，真实一屏约 11 小节。补三样：播放中收起标题栏和次要控件（沉浸模式）、支持 Fullscreen API 的平台（安卓）播放即全屏、PWA `manifest` + `apple-mobile-web-app-capable` 让 iPhone 从主屏幕打开时没有浏览器栏。**iPhone 上网页不能调用全屏接口**（只有 `<video>` 例外），别在这上面花时间。

## 数据支撑

见上表；两遍排版上线后手机默认配置：每行 ≤3 小节、单谱表、缩放 0.7，桌面端 444 光标步与三行谱表与改动前完全一致（回归测试锁死）。

## 适用范围

- 适用于：OSMD 1.8.x 渲染多声部谱、主声部明确、手机竖屏
- 不适用于：需要同时盯两个声部的用户（伴奏者）——给一个开关让他们打开钢琴谱，默认别开；OSMD 更高版本若新增了"每行固定小节数"规则可以直接用，但仍要留意孤行问题
