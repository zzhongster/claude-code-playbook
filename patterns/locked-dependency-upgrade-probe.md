# 锁死依赖的升级评估探针法 — 用实测报文替代 changelog 阅读

> 来源:trade-agent-data A3 薄片(2026-09-02),MCP SDK 1.28.1→2.1.1 升级。
> 该依赖曾因被动升级导致线上崩溃循环而锁死("禁止顺手升"),本次为正式评估+迁移。
> 实绩:评估探针半天出结论,迁移 diff 48 行,1448 单测全绿,canary 当天上线,
> 6 种客户端形态生产实测零破坏。

## 适用场景

框架级依赖(SDK/协议库/序列化层)的大版本升级,且满足任一:
- 该依赖曾出过升级事故被钉死版本;
- 它坐在**对外契约面**上(下游按字面报文做程序判断);
- 官方 changelog 说"重构了核心类"这种话。

## 核心主张:评估与实施分两段,评估靠实测不靠文档

**第一段是 spike**(产出=升/不升的评估报告,代码全部 throwaway);
**第二段才是实施**(拿到拍板后,TDD 从头做,不复用探针代码)。
评估报告本身是正式交付物,commit 进 docs/ 并同步任务系统。

## 探针清单(按序,每步都比读文档准)

1. **摸依赖面**:grep 全仓 import——注意 **scripts/、tools/、installer/ 也要扫**,
   不只 src/(本次真实 miss:e2e 脚本里的旧版客户端用法漏扫,靠 code review 兜回)。
2. **验二手信息**:issue/备忘里"X 类改名了"之类的调研快照先验真。
   本次"Server→MCPServer"实为 FastMCP 层改名,低层 Server 类原样保留——
   迁移面比传闻小一个量级。
3. **零改动全量测试**:隔离 venv 装新版本 + 代码副本(scratchpad,不碰主工作区,
   PYTHONPATH 压过 editable 安装),**一行不改直接跑全量测试**。
   崩的就是真实迁移面;不崩的就是无耦合面。比读迁移指南快且无遗漏。
4. **最小对照服务**:新旧两版各起一个最小服务(复刻生产的 SDK 用法:同样的
   注册方式/返回形态/异常路径),同一组探针请求打两边,**报文 diff**。
   探针组至少含:正常调用/业务异常/参数超限/未知输入/目录列表。
5. **全目录规范化 diff**:真实服务新旧两版的完整目录(tools/list 之类)
   `json sort_keys 后 diff`——为空即对外面零漂移,一条命令抵一页兼容性论述。
6. **客户端兼容矩阵**:每种**真实调用方形态**一格(裸 HTTP/各版本 SDK/桥接工具/
   stdio),标注对应的生产角色(哪个下游/哪个安装渠道)。缺一格就留到 canary 补,
   在报告里写明。
7. **行为特征区分新旧**:找一个能从响应区分打到新旧版本的信号
   (本次用 serverInfo.version),canary 验证时不用猜流量落点。

## 高发差异类型(评估时主动找,别等炸)

- **框架"免费行为"被移除**:旧版在框架层白送的校验/异常包装/返回值包装,
  新版删了——你的代码"没改"但对外行为变了,而**现有测试可能全绿**
  (测试从没钉过框架层的行为)。对策:grep 旧版源码定位该行为的实现点,
  在新版里确认存亡;移除的在自己的适配层复刻,并补钉行为的测试。
- **wire 格式与代码 API 分离**:pydantic alias 类机制下,Python 字段名全变
  (camelCase→snake_case)而 wire 不变——契约看 wire,迁移看 API,别混。
- **幽灵依赖显形**:旧版的传递依赖(本次 httpx、jsonschema)新版不再带,
  自己代码在用的要转显式声明。
- **新版默认行为**:遥测/日志/限额类默认值(本次 OpenTelemetry 默认埋点——
  查清是 no-op api 还是真外发)。
- **包名裂变**:大版本可能拆新包名(TS SDK 2.x 是 @modelcontextprotocol/client,
  旧包名停在 1.x)——查"没有 2.x"之前先确认没改名。

## 实施段纪律

- 探针代码**全部丢弃**,实施走 TDD:先写钉新行为的失败测试(异常包装文案逐字、
  校验拒绝语义、版本号非空),再迁移。探针学到的知识进脑子,不进 cherry-pick。
- 对外文案逐字断言(`==`,不是 `startswith` 能省则省)。
- canary 用**独立目录+独立镜像 tag**构建,别 rsync 覆盖主容器的构建目录。
- nginx map 按 Authorization 路由 canary 时,长 token 会撞
  `map_hash_bucket_size` 缺省 64——名单有真实条目前先加 256。

## 为什么值得

被锁死的依赖每拖一个月,生态漂移的互操作风险涨一分;而"怕再出事故"的心理
成本让它一直没人碰。探针法把"怕"变成半天的实测清单——结论要么是
"迁移面 48 行+已验证",要么是"这三个报文 diff 就是不升的证据",
两种都能直接拍板。
