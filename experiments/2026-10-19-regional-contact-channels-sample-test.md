# 实验：联系人库查不到人时，各地区的免费补充渠道到底管不管用（18 家样本 + 马来西亚政府通讯录）

> 来源：trade-agent-data 水务展会观众名单 67 家补联系人（2026-10-19）
> 前置：联系人库（上游含 Apollo / ContactOut / Hunter）+ 领英检索已跑完，剩下的都是它们查不到的公司

## 问题

B2B 补联系人，主流数据库在小国、政府机构、家族企业上覆盖很薄。这批 67 家里 16 家联系人库一个人都查不到。**有没有不花钱、按地区可复用的补充渠道？**

## 验收标准

**现任负责人姓名 + 本人邮箱或手机**。公司总机、info@、sales@ 一律不算。只拿到姓名 = 部分达标。

## 方法

从没补够联系人的公司里挑 18 家，覆盖 7 个地区；每家试 2～4 个当地免费渠道（搜索 + 抓页面）；找到姓名的推测邮箱 + 独立验证（每个域名同时验一个编造地址，防全收服务器），找到手机的查 WhatsApp。

## 结果

| 结果 | 家数 |
|---|---|
| 完全达标（姓名 + 本人邮箱/手机） | 4（22%） |
| 能联系上（公开手机已开通 WhatsApp / 职务邮箱 ceo@），但对不上具体人 | 3 |
| 只拿到现任负责人姓名 | 7 |
| 无收获 | 4 |

| 地区 | 有效渠道 | 无效 / 要小心的 |
|---|---|---|
| 日本 | 官网「会社概要」「役员紹介」给姓名；**推测「姓@域名」命中**（社长 takeda@ 验证有效） | 大一点的公司推测不中 |
| 韩国 | 官网「회사소개」、招聘站（JobPlanet / Saramin）、行业协会会员页给代表姓名 | **推测邮箱基本不中**——中小企业负责人多用 naver/gmail，企业域名下只有 ceo@ 这类职务邮箱 |
| 越南 | 税号查询站给法定代表人 | 本次没带出新联系方式 |
| 俄罗斯 | rusprofile / checko 等工商查询给总经理姓名 | **同名公司多**（一个品牌 3 家法人），官网不写税号就定不了，宁缺勿错 |
| 蒙古 | 当地媒体报道给执行总监姓名 → 推测邮箱验证有效 | |
| 中东 / 北非 | **官网直接公布手机号，4/4 开通 WhatsApp** | 对不上具体人 |
| 南亚 | **行业协会会员名录**（孟加拉 BAIRA）给业主姓名 + 手机，已开通 WhatsApp | |
| 撒哈拉以南非洲 | 官网高管页给现任负责人（发现原表的总经理已卸任） | 推测邮箱全无效 |
| 缅甸 | 领英能找到董事 → 联系人库取到企业邮箱 | |

**政府机构单列**：马来西亚各部委官网普遍公布「Direktori Kakitangan」（职员通讯录：姓名、职位、邮箱、直线电话），按部门筛选即可取到处长级。一次补了 8 位处长级官员，零成本、来源最权威。其中一个部委网站对程序访问做了拦截，改用浏览器正常打开逐部门查看，不绕拦截。

**付费本地工具（SignalHire）**：免费账号查到第 6 家就被导向付费页，搜不了；日韩中小企业不在它的公司库里。免费额度只能给「已知领英主页」的人解锁，而缺口公司恰恰找不到领英——**免费额度测不出这类工具的真实价值**，要测就买一个月、拿同一批缺口样本做对比。

## 结论

1. **姓名几乎处处找得到，难的是本人联系方式。** 官网负责人页、工商登记站、行业协会名录、当地媒体，基本都能给出现任负责人。
2. **渠道按地区选**：日本推测邮箱；中东、北非、南亚取公开手机号查 WhatsApp；政府机构查官网职员通讯录；协会名录各地都值得先看。
3. **验收口径要分地区**：在 WhatsApp 为主的地区，「能直接 WhatsApp 上的负责人手机」比「本人企业邮箱」更实用。
4. **这条免费链路可以固定为联系人库之后的兜底**：官网 / 工商 / 协会名录找姓名 → 推测邮箱 + 独立验证 / 公开手机号 + WhatsApp 核验。
5. **原表的信息会过时**（总经理换人），补联系人时顺带就能发现。

## 局限

- 样本小（18 家），各地区只有 1～4 家，命中率不能外推，只能看渠道是否有效
- 推测邮箱的「验证有效」只说明可投递，不保证是本人在看（如 takeda@ 可能是同姓的其他人）
