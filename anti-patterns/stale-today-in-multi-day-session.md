# 跨天会话里，「今天」和挂起的提议都会过期

> 来源：TOUCH 2.0 日报补做（2026-08-11 ~ 08-13，TOU-340）

## 现象

同一个 Claude Code 会话 8/11 开始、8/13 继续。两处险些出错：

1. 8/11 跑过一次 `date` 后，后续发言一直沿用「今天 = 8/11」，8/13 还在说「今晚 21:30 首跑」；
2. 8/11 生成了两张「当日」报表并向人提议「要不要发群」；人 8/13 才回复——若回的是「发吧」，两天前的图就会以当日名义进群。是人一句「今天已经 13 号了」拦下的，不是 AI 自查出来的。

## 规则

1. **时间敏感的话与动作，开口/动手前重跑 `date`**。触发条件：长会话、被打断后恢复、跨天续聊。会话上下文里的时间戳是缓存，不是时钟；
2. **执行「早前提议、刚被批准」的动作前，重验提议时的前提**。批准针对的是提议那一刻的世界；世界变了，把新状态摆出来重新问，而不是拿着旧授权直接干。

## 更一般的形状

会话上下文是一份**越来越旧的快照**：日期、分支位置、PR 状态、别人有没有回复，全都在会话外持续变化。凡是「基于上下文里的事实做不可逆动作」之前，那个事实值不值一次现查，取决于它多容易变——日期每天变、PR 状态每分钟变，都值。
